<task type="auto">
  <name>Task 1: Create death explosion particle effect</name>
  <files>lib/game/effects/death_particles.dart, lib/game/pulse_game.dart, lib/game/config/game_config.dart</files>
  <action>
  Create a factory function or class `DeathParticles` that returns a `ParticleSystemComponent` (from `package:flame/particles.dart`). The effect: 15-20 small diamond/triangle-shaped fragments burst outward from a given position with random velocities in all directions, then fade out over ~0.5s.

  Implementation approach:
  - Use `Particle.generate()` to create multiple particles
  - Each particle: `AcceleratedParticle` with random initial velocity (spread in 360 degrees, speed 100-300 px/s), slight gravity pull downward (acceleration Vector2(0, 200))
  - Wrap each in `FadingParticle` (fades to 0 opacity)
  - Wrap each in `ComputedParticle` to render small colored shapes (use Canvas.drawPath for diamond fragments matching playerColor)
  - Lifespan: 0.4-0.6 seconds
  - Total particle system lifespan: 0.6s

  Add to GameConfig: `deathParticleCount: 18`, `deathParticleSpeed: 250.0`, `deathParticleLifespan: 0.5`

  Wire in PulseGame.gameOver(): after triggering shake, add `DeathParticles.create(position: player.position)` to the world. The particles will animate during the 0.3s pre-pause window and the ParticleSystemComponent auto-removes when done.

  Note: ParticleSystemComponent continues to render after game pause ONLY if added before pause. Since death delays pause by 0.3s (from 04-01), particles get time to burst. Any remaining particles will be frozen mid-animation when pause hits — this looks fine (dramatic freeze frame).
  </action>
  <verify>C:/flutter/bin/flutter analyze --no-pub && C:/flutter/bin/flutter build web --no-pub</verify>
  <done>Death explosion spawns 18 colored particle fragments bursting outward from player position. No analysis errors.</done>
