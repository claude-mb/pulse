<task type="auto">
  <name>Task 1: Create background pulse component</name>
  <files>lib/game/components/background_pulse.dart, lib/game/pulse_game.dart, lib/game/config/game_config.dart</files>
  <action>
  Create `BackgroundPulse` extending `Component` with `HasGameReference<PulseGame>` and custom render — a full-screen color overlay that pulses (brightens and dims) in rhythm with obstacle spawning.

  Implementation:
  - Track a `_pulsePhase` (0.0 to 1.0) that cycles based on the current spawn interval
  - In update(): increment _pulsePhase by `dt / currentInterval` where currentInterval is calculated the same way as in ObstacleSpawner (base interval × difficulty intervalMultiplier × breather bonus if applicable). Read these from game.difficultyManager.
  - When _pulsePhase >= 1.0, reset to 0.0 (new cycle)
  - In render(): draw a full-screen rectangle with accentColor at varying opacity. Use a smooth curve: opacity = `baseOpacity + pulseAmplitude * sin(_pulsePhase * pi)^2`. This creates a gentle "breathe" that peaks mid-cycle.
  - Base opacity: 0.0 (invisible at rest), amplitude scales with difficulty: 0.03 at level 0, up to 0.08 at level 4.
  - Priority: -5 (above background grid at -10, below game objects)

  Add to GameConfig: `pulseBaseAmplitude: 0.03`, `pulseMaxAmplitude: 0.08`, `pulseColor: Color(0xFF16213E)`

  Add BackgroundPulse to world in PulseGame.onLoad(). The component auto-syncs to game rhythm through its update() reading from difficultyManager.
  </action>
