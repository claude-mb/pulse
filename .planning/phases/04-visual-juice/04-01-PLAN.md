<task type="auto">
  <name>Task 1: Create ScreenShake effect component</name>
  <files>lib/game/effects/screen_shake.dart, lib/game/config/game_config.dart</files>
  <action>
  Create `ScreenShake` extending `Component` that takes `intensity` (max pixel offset) and `duration` parameters. In update(), apply random x/y offsets to the parent's position (will be added to camera.viewfinder). Use decaying intensity: `intensity * (1 - elapsed/duration)` so shake diminishes. When duration expires, restore parent position to base (worldWidth/2, worldHeight/2) and removeFromParent().

  Use dart:math Random for offset generation. Each frame, set viewfinder position to base + random offset within current intensity range.

  Add to GameConfig:
  - shakeIntensityDeath: 8.0 (strong)
  - shakeIntensityNearMiss: 3.0 (subtle)
  - shakeDurationDeath: 0.3
  - shakeDurationNearMiss: 0.15
  - nearMissThreshold: 70.0 (center-to-center px distance)

  Do NOT use MoveEffect — random per-frame jitter needs manual position control, not tweened animation.
  </action>

<task type="auto">
  <name>Task 2: Wire shake to death and implement near-miss detection</name>
  <files>lib/game/pulse_game.dart, lib/game/components/obstacle.dart</files>
  <action>
  **Death shake:** In PulseGame.gameOver(), do NOT set `paused = true` immediately. Instead: set state to gameOver, swap overlays (remove HUD, add GameOver), add ScreenShake to `camera.viewfinder` with death intensity/duration. Use `Future.delayed(Duration(milliseconds: 300))` to set `paused = true` AFTER shake plays out. Guard the delayed callback: only set paused if `_state == GameState.gameOver` (user may have restarted during the shake window). In resetGame() and startGame(), ensure paused is set to false to cancel any pending effect.

  Add a helper method `triggerShake(double intensity, double duration)` on PulseGame that removes any existing ScreenShake children from camera.viewfinder before adding a new one (prevents stacking).

  **Near-miss detection:** Add `HasGameReference<PulseGame>` mixin to Obstacle (import pulse_game.dart). Add `bool _passedPlayerZone = false` field. In update(), after position update, check: if `!_passedPlayerZone && position.y > GameConfig.playerStartY + GameConfig.playerSize / 2`. When true, set `_passedPlayerZone = true` and if `game.state == GameState.playing`, compute `(position.x - game.player.position.x).abs()`. If less than `GameConfig.nearMissThreshold`, call `game.triggerShake(GameConfig.shakeIntensityNearMiss, GameConfig.shakeDurationNearMiss)`.
  </action>
