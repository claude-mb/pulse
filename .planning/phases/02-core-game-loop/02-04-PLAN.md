<objective>
Implement the death and instant restart flow — zero friction retry loop.

Purpose: The restart loop IS the game's addiction mechanism. Flappy Bird proved that "die → tap → playing again in <0.5s" creates compulsive replay. Any friction in the restart loop kills engagement.
Output: Seamless death → game over → tap to restart → playing cycle with clean world state on each attempt.
</objective>
