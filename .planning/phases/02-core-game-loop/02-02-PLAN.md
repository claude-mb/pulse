<task type="auto">
  <name>Task 2: Create ObstacleSpawner with timer-based spawning</name>
  <files>lib/game/managers/obstacle_spawner.dart, lib/game/pulse_game.dart, lib/game/config/game_config.dart</files>
  <action>
    1. Create `lib/game/managers/obstacle_spawner.dart`:
       - Extend `Component` with `HasGameReference<PulseGame>`
       - Use a `Timer` from `package:flame/timer.dart` (or `dart:async` Timer equivalent)
         Actually, use Flame's built-in `TimerComponent` approach: maintain a double accumulator in `update(dt)`
       - In `update(double dt)`:
         a. Accumulate time: `_elapsed += dt`
         b. When `_elapsed >= GameConfig.spawnInterval`:
            - Reset: `_elapsed -= GameConfig.spawnInterval` (subtract, don't zero — preserves timing accuracy)
            - Generate random x position between GameConfig.playerMinX and GameConfig.playerMaxX (using Flame's `Random()`)
            - Create Obstacle at (randomX, GameConfig.obstacleSpawnY)
            - Add to parent (world): `parent?.add(obstacle)`
       - Import `dart:math` for Random

    2. Add ObstacleSpawner to world in PulseGame:
       - Create `late ObstacleSpawner obstacleSpawner;` field
       - Add to world in onLoad (after player)

    3. Add a method to clear all obstacles from world:
       - On PulseGame, add `void clearObstacles()`:
         ```
         world.children.whereType<Obstacle>().toList().forEach((o) => o.removeFromParent());
         ```
       - Call `clearObstacles()` in `startGame()` and `resetGame()`
       - Also reset spawner timer: add `reset()` method on ObstacleSpawner that zeros `_elapsed`

    Obstacles should only spawn during GameState.playing — check `game.state == GameState.playing` before spawning.
    Use `dart:math.Random` (not `Random()` inside update — create once in constructor or as field).
  </action>
