    2. Add dodge methods to Player:
       - `dodgeLeft()`: Move player left by GameConfig.playerDodgeDistance, clamped to playerMinX
       - `dodgeRight()`: Move player right by GameConfig.playerDodgeDistance, clamped to playerMaxX
       - Use Flame's `MoveEffect.to()` with `EffectController(duration: 0.1)` for snappy, smooth movement
       - Before adding a new MoveEffect, remove any existing one (prevent stacking) by using `children.whereType<MoveEffect>().forEach((e) => e.removeFromParent())`

    3. Reset player position on game restart:
       - Add a `resetPosition()` method on Player that sets position back to center
       - Call `player.resetPosition()` in PulseGame.resetGame() and PulseGame.startGame()

    The dodge should feel SNAPPY — 0.1s duration is fast enough to feel responsive.
    Using MoveEffect instead of manual update() ensures smooth interpolation even at variable frame rates.
    Do NOT use manual position updates in update() — MoveEffect handles easing correctly.
