  <name>Task 1: Calibrate movement and obstacle values for good feel</name>
  <files>lib/game/config/game_config.dart, lib/game/components/obstacle.dart, lib/game/managers/obstacle_spawner.dart</files>
  <action>
    1. Review and adjust GameConfig values with gameplay feel in mind:

       **Player movement:**
       - dodgeDistance: 120.0 → evaluate if this feels right. With playerMinX=40 and playerMaxX=360, that's ~320 pixels of play space. At 120px per dodge, player can reach any position in ~3 taps. This is reasonable — keep or adjust based on obstacle spread.
       - Dodge animation duration (currently 0.1s in MoveEffect) — keep snappy. Under 0.15s feels responsive.

       **Obstacles:**
       - obstacleSpeed: 200.0 → With 800px world height + 30px spawn buffer, time to cross screen = ~4.15 seconds. This is probably too slow for engaging gameplay. Try 250-300 for more urgency.
       - spawnInterval: 1.5s → At 200 speed, this means obstacles are ~300px apart vertically. Reasonable starting point but should probably be 1.0-1.2s for more density.
       - obstacleWidth: 60.0 → On a 400px-wide world, one obstacle blocks 15% of space. This is fair. Multiple obstacles at different x positions would block more — Phase 3 handles patterns.

    2. Add obstacle width variation for visual interest:
       - Add `static const double obstacleMinWidth = 50.0;`
       - Add `static const double obstacleMaxWidth = 80.0;`
       - Update ObstacleSpawner to randomize width between min and max
       - This adds slight unpredictability that keeps players attentive

    3. Ensure obstacle spawn positions don't cluster:
       - Track last spawn x position in ObstacleSpawner
       - Ensure next spawn is at least `obstacleWidth` away from last position
       - This prevents impossible sequences where two obstacles overlap the same spot

    Do NOT add difficulty escalation — that's Phase 3.
    Do NOT add complex patterns — that's Phase 3.
    Keep this about the FEEL of individual interactions, not strategic complexity.
  </action>
