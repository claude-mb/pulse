  <action>Create lib/utils/daily_challenge_repository.dart following the ScoreRepository singleton pattern:

```dart
class DailyChallengeRepository {
  static final DailyChallengeRepository instance = DailyChallengeRepository._();
  DailyChallengeRepository._();

  late SharedPreferences _prefs;
  bool _initialized = false;
```

SharedPreferences keys:
- `'daily_date'` (String, YYYY-MM-DD) — which day the current daily stats belong to
- `'daily_best_score'` (int) — best score for today's daily challenge
- `'daily_attempts'` (int) — number of daily attempts today
- `'daily_streak'` (int) — consecutive days played
- `'daily_last_streak_date'` (String, YYYY-MM-DD) — last date that contributed to streak

Methods:
- `Future<void> initialize()` — load SharedPreferences, call _checkDayRollover()
- `void _checkDayRollover()` — compare stored daily_date to today. If different: set daily_date to today, reset daily_best_score to 0, reset daily_attempts to 0. Do NOT touch streak here (streak updates on first play of the day).
- `String get _todayString` — `DateTime.now().toIso8601String().substring(0, 10)` for YYYY-MM-DD
- Getters: `int get dailyBestScore`, `int get dailyAttempts`, `int get streak`
- `Future<bool> recordDailyGame({required int score})`:
  1. Increment daily_attempts
  2. If score > dailyBestScore, update daily_best_score, set wasNewBest = true
  3. If this is the first attempt today (old attempts was 0), call _updateStreak()
  4. Return wasNewBest

- `void _updateStreak()`:
  1. Read daily_last_streak_date
  2. Compute yesterday = DateTime.now().subtract(Duration(days: 1)) formatted as YYYY-MM-DD
  3. If last_streak_date == yesterday: streak += 1 (consecutive day)
  4. Else if last_streak_date != today: streak = 1 (new streak or first ever)
  5. (If last_streak_date == today, streak already counted — skip)
  6. Set daily_last_streak_date = today

Use fire-and-forget pattern for all SharedPreferences writes (no await needed for UX responsiveness). Guard all getters with `if (!_initialized) return 0;` like ScoreRepository.</action>
