  <name>Task 2: Create iOS build and submission guide</name>
  <files>docs/ios-release-guide.md</files>
  <action>
  Create `docs/ios-release-guide.md` with complete step-by-step instructions. This guide is needed because iOS builds require macOS + Xcode, unavailable on the current Windows machine.

  Sections:

  **1. Prerequisites**
  - macOS computer with Xcode 15+ installed
  - Apple Developer account ($99/year) — enroll at developer.apple.com
  - CocoaPods: `sudo gem install cocoapods`
  - Flutter SDK installed on the Mac

  **2. Initial Setup on Mac**
  - Clone/copy repo to Mac
  - Run `flutter pub get`
  - Run `cd ios && pod install && cd ..`
  - Open `ios/Runner.xcworkspace` in Xcode (NOT Runner.xcodeproj)

  **3. Signing Configuration**
  - In Xcode: select Runner target → Signing & Capabilities tab
  - Check "Automatically manage signing"
  - Select your Team (Apple Developer account)
  - Xcode creates provisioning profiles automatically
  - Verify no signing errors appear

  **4. Build Release Archive**
  - Option A (CLI): `flutter build ios --release`
  - Option B (Xcode): Product → Archive (select "Any iOS Device" as destination first)
  - Archive appears in Xcode Organizer (Window → Organizer)

  **5. Upload to App Store Connect**
  - In Xcode Organizer: select archive → Distribute App → App Store Connect → Upload
  - Or via CLI: `xcrun altool --upload-app -f Runner.ipa -t ios -u APPLE_ID -p APP_SPECIFIC_PASSWORD`
  - Build processes in App Store Connect (takes ~15 min)

  **6. Alternative: CI/CD (Recommended for ongoing development)**
  - **Codemagic**: Add `codemagic.yaml` to repo root. Free tier includes 500 build minutes/month with macOS VMs. Handles signing, building, and uploading.
  - **GitHub Actions**: Use `macos-latest` runner + `subosito/flutter-action`. Set up certificates via match or manual provisioning.

  Keep practical — specific commands and UI paths, not theory.
  </action>
  <verify>
  - File `docs/ios-release-guide.md` exists
  - Contains all 6 sections (Prerequisites through CI/CD)
  - Commands are correct and specific
  </verify>
