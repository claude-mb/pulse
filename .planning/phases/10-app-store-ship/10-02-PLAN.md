<task type="auto">
  <name>Task 2: Create release signing configuration</name>
  <files>android/app/upload-keystore.jks, android/key.properties, android/app/build.gradle.kts, .gitignore</files>
  <action>
  1. Generate upload keystore using keytool:
     ```
     keytool -genkey -v -keystore android/app/upload-keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload -storepass pulse2026release -keypass pulse2026release -dname "CN=Pulse Game, O=Pulse Game, L=Unknown, ST=Unknown, C=US"
     ```
     IMPORTANT: User MUST change these passwords before actual store submission and MUST back up the keystore securely. Loss of keystore = inability to update app on Play Store.

  2. Create `android/key.properties`:
     ```
     storePassword=pulse2026release
     keyPassword=pulse2026release
     keyAlias=upload
     storeFile=app/upload-keystore.jks
     ```

  3. Update `android/app/build.gradle.kts` — add before the `android {` block:
     ```kotlin
     val keystorePropertiesFile = rootProject.file("key.properties")
     val keystoreProperties = java.util.Properties()
     if (keystorePropertiesFile.exists()) {
         keystoreProperties.load(java.io.FileInputStream(keystorePropertiesFile))
     }
     ```
     Inside `android {` block, add signingConfigs before buildTypes:
     ```kotlin
     signingConfigs {
         create("release") {
             keyAlias = keystoreProperties["keyAlias"] as String?
             keyPassword = keystoreProperties["keyPassword"] as String?
             storeFile = keystoreProperties["storeFile"]?.let { file(it as String) }
             storePassword = keystoreProperties["storePassword"] as String?
         }
     }
     ```
     Update buildTypes.release to use release signing:
     ```kotlin
     release {
         signingConfig = signingConfigs.getByName("release")
     }
     ```

  4. Add to `.gitignore`:
     ```
     # Release signing
     android/app/upload-keystore.jks
     android/key.properties
     ```
  </action>
  <verify>
  - File `android/app/upload-keystore.jks` exists
  - File `android/key.properties` exists
  - `grep "upload-keystore.jks" .gitignore` matches
  - `grep "key.properties" .gitignore` matches
  </verify>
  <done>Release keystore generated, key.properties created, build.gradle.kts configured for release signing, sensitive files in .gitignore.</done>
</task>
