<task type="auto">
  <name>Task 1: Generate app icon source image</name>
  <files>pubspec.yaml, tool/generate_icon.dart, assets/icon/app_icon.png</files>
  <action>
  1. Add `image: ^4.5.3` to dev_dependencies in pubspec.yaml and run `flutter pub get`.

  2. Create directory `assets/icon/`.

  3. Create `tool/generate_icon.dart` — a Dart CLI script that generates a 1024x1024 PNG app icon:
     - Background: solid #1A1A2E (dark navy, matching game background)
     - Center diamond: filled #E94560 (neon red, the default player color), sized ~500px tall rotated 45°
     - Glow layer: draw a slightly larger diamond (~560px) behind in #E94560 at ~40% opacity for soft glow
     - Use the `image` package (img.Image, img.fill, manual pixel iteration for diamond fill)
     - Diamond vertices: center (512,512) with half-size 250px. For each pixel (x,y), compute Manhattan distance from center: d = |x-512| + |y-512|. If d < 250, fill with player color. If d is between 250 and 280, fill with player color at opacity proportional to (280-d)/30 for glow effect.
     - Output to `assets/icon/app_icon.png`

  4. Run the script: `dart run tool/generate_icon.dart`
  </action>
  <verify>File `assets/icon/app_icon.png` exists and is a valid PNG. `dart run tool/generate_icon.dart` exits with code 0.</verify>
  <done>A 1024x1024 PNG icon with diamond shape on dark background exists at assets/icon/app_icon.png</done>
</task>

<task type="auto">
  <name>Task 2: Generate platform icons and splash screen</name>
  <files>pubspec.yaml, android/app/src/main/res/mipmap-*/ic_launcher.png, ios/Runner/Assets.xcassets/AppIcon.appiconset/*</files>
  <action>
  1. Add to dev_dependencies in pubspec.yaml:
     - `flutter_launcher_icons: ^0.14.3`
     - `flutter_native_splash: ^2.4.4`

  2. Add flutter_launcher_icons configuration to pubspec.yaml (top level):
     ```yaml
     flutter_launcher_icons:
       android: "ic_launcher"
       ios: true
       image_path: "assets/icon/app_icon.png"
       adaptive_icon_background: "#1A1A2E"
       adaptive_icon_foreground: "assets/icon/app_icon.png"
     ```

  3. Add flutter_native_splash configuration to pubspec.yaml (top level):
     ```yaml
     flutter_native_splash:
       color: "#1A1A2E"
       android: true
       ios: true
     ```

  4. Run `flutter pub get`.
  5. Run `dart run flutter_launcher_icons` to generate all icon sizes.
  6. Run `dart run flutter_native_splash:create` to generate splash screens.

  Do NOT add a splash image — just the dark background color for a clean, fast-loading splash that matches the game. Do NOT modify any Dart source files.
  </action>
