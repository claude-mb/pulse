  <files>lib/game/pulse_game.dart, lib/game/components/tap_indicator.dart</files>
  <action>
    1. Create TapIndicator component (lib/game/components/tap_indicator.dart):
       - Extends PositionComponent
       - Renders a small circle (radius ~15) at tap position with white color
       - Uses OpacityEffect or ScaleEffect to animate: spawn at full size, fade/shrink out over 0.3s
       - Use built-in Effects system (do NOT hand-roll animation — see research dont_hand_roll)
       - Calls removeFromParent() when animation completes (use onComplete callback or RemoveEffect)
       - Anchor set to Anchor.center so it appears centered on tap point

    2. Add TapCallbacks mixin to PulseGame:
       - Override onTapDown(TapDownEvent event) on PulseGame
       - Convert tap screen position to world coordinates using camera
       - Spawn a TapIndicator at the world position
       - Add the TapIndicator to world (not directly to game)

    Note: We use game-level TapCallbacks here for detecting taps anywhere on canvas.
    In Phase 2, input will move to component-level TapCallbacks on the Player entity.
    This is intentional — proving game-level input works, then refining later.

    Do NOT add any gameplay logic — just visual proof that taps are detected and positioned correctly.
  </action>
