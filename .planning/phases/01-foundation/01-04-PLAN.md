<task type="auto">
  <name>Task 1: Implement game state enum and transition methods</name>
  <files>lib/game/pulse_game.dart</files>
  <action>
    1. Create a GameState enum at the top of pulse_game.dart (or a separate file):
       enum GameState { menu, playing, paused, gameOver }

    2. Add state management to PulseGame:
       - GameState _state = GameState.menu (start in menu)
       - GameState get state => _state
       - void startGame(): state → playing, remove MainMenu overlay, add HUD overlay, paused = false
       - void pauseGame(): state → paused, add Pause overlay, paused = true
       - void resumeGame(): state → playing, remove Pause overlay, paused = false
       - void gameOver(): state → gameOver, remove HUD overlay, add GameOver overlay, paused = true
       - void resetGame(): state → playing, remove GameOver overlay, add HUD overlay, paused = false
         (Phase 2 will also reset player position, score, obstacles here)
       - void returnToMenu(): state → menu, remove all game overlays, add MainMenu overlay, paused = true

    3. In onLoad(), set paused = true initially (game shouldn't run until player taps Play)

    4. Guard tap indicators: in onTapDown, add `if (state != GameState.playing) return;`
       so tap indicators only appear during gameplay.

    Do NOT add actual gameplay logic — just state transitions and overlay management.
    Do NOT use a separate state management library — simple enum + methods is sufficient.
  </action>
  <verify>`flutter analyze` passes. State transitions are consistent (each method sets state and manages overlays).</verify>
  <done>PulseGame has GameState enum, all transition methods, game pauses in menu/gameOver states, tap indicators only in playing state</done>
</task>
