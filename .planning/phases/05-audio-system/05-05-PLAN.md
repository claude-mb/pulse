<task type="auto">
  <name>Task 1: Implement mute/volume toggle logic in AudioManager</name>
  <files>lib/utils/audio_manager.dart</files>
  <action>
Ensure AudioManager properly handles mute and volume state in all play methods:

**Mute enforcement:**
- `playSfx()`: if `sfxMuted`, return immediately without playing.
- `playBgm()`: if `bgmMuted`, track that BGM was requested but don't play. When unmuted, start playing if a BGM was requested.
- Store the last-requested BGM name so unmuting can resume it.

**Volume application:**
- `playSfx()`: multiply the passed volume by `sfxVolume` before playing. For AudioPool.start(), pass `volume: effectiveVolume`.
- `playBgm()`: set BGM player volume to `bgmVolume`. For FlameAudio.bgm, the volume is set via the underlying player.

**Toggle methods:**
- `toggleSfxMute()` — flips sfxMuted. No side effects needed (next play call checks).
- `toggleBgmMute()` — flips bgmMuted. If unmuting and BGM was requested, start it. If muting, pause BGM.

**Volume setters:**
- `setSfxVolume(double v)` — clamps 0-1, stores in sfxVolume.
- `setBgmVolume(double v)` — clamps 0-1, stores in bgmVolume, updates active BGM player volume if playing.

Note: persistent storage comes in Phase 6. For now, defaults reset on app restart.
  </action>
  <verify>Unit-level verification: set sfxMuted = true, call playSfx — no sound. Set bgmMuted = true during playback — BGM pauses. Unmute — BGM resumes. Verify volume scaling works (sfxVolume = 0.5 should halve SFX loudness).</verify>
  <done>AudioManager mute toggles and volume setters work correctly. Muting SFX silences all SFX. Muting BGM pauses/resumes. Volume scaling applied to all play calls.</done>
</task>

<task type="auto">
  <name>Task 2: Add audio controls to pause overlay</name>
  <files>lib/screens/pause_overlay.dart</files>
  <action>
Add audio toggle controls to the existing pause overlay widget:

**Layout:** Below the existing pause content (Resume/Menu buttons), add a row of two icon toggle buttons:
- **SFX toggle:** Icon changes between `Icons.volume_up` (unmuted) and `Icons.volume_off` (muted). Tapping calls `audioManager.toggleSfxMute()`.
- **Music toggle:** Icon changes between `Icons.music_note` (unmuted) and `Icons.music_off` (muted). Tapping calls `audioManager.toggleBgmMute()`.

**Styling:**
- Use IconButton with the existing text color (GameConfig.textColor / white).
- Wrap in a Row with MainAxisAlignment.center, spaced apart.
- Add subtle labels below each icon: "SFX" and "MUSIC" in small text.
- Muted state: icon at 50% opacity. Unmuted: full opacity.

**State management:**
- The pause overlay is a StatefulWidget (or should be made one if it isn't).
- Call setState after toggle to update icon appearance.
- Access AudioManager via `AudioManager.instance` (singleton).

**Important:** Do NOT add volume sliders — simple mute toggles are sufficient for v1. Volume sliders add UX complexity. Players who want less sound can mute; players who want it can keep it on.

Keep the existing pause overlay layout intact — add the audio row below the existing buttons with some spacing.
