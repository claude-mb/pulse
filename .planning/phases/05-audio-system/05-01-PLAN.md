  <action>
Create a standalone Dart CLI script at `tool/generate_audio.dart` that generates WAV audio files for all game sounds. The script uses `dart:io` and `dart:typed_data` to write raw PCM WAV files (44100Hz, 16-bit mono).

Generate these sound files:
1. **dodge_whoosh.wav** (~0.15s) — white noise burst with fast attack/decay envelope. Quick breathy swoosh.
2. **death_impact.wav** (~0.3s) — low-frequency sine (80Hz) mixed with noise burst, heavy attack then rapid decay. Punchy impact.
3. **near_miss.wav** (~0.2s) — rising sine sweep from 400Hz to 1200Hz with quick decay. Tense "zing" sound.
4. **restart_chime.wav** (~0.25s) — two ascending sine tones (440Hz then 660Hz, 0.1s each with 0.05s overlap). Bright restart cue.
5. **spawn_cue.wav** (~0.08s) — very short low sine pulse (120Hz) with sharp attack/decay. Subtle bass tick matching visual pulse.
6. **menu_select.wav** (~0.1s) — short sine blip at 880Hz with fast decay. Clean UI click.

WAV file structure:
- RIFF header (44 bytes): "RIFF", file size, "WAVE", "fmt " chunk (16 bytes PCM format, 1 channel, 44100Hz, 16-bit), "data" chunk header + size
- Raw PCM samples: signed 16-bit little-endian

Use simple synthesis functions:
- `sine(freq, t)` — sine wave at frequency
- `noise(t)` — white noise from Random
- `envelope(t, attack, decay, total)` — amplitude envelope

Run the script with `dart run tool/generate_audio.dart` to populate assets/audio/.

Do NOT use any external packages — pure dart:io + dart:math + dart:typed_data.

```
class AudioManager {
  // Singleton pattern matching project style
  static final AudioManager instance = AudioManager._();
  AudioManager._();

  bool _initialized = false;

  // Audio pools for frequently-played SFX (low latency)
  late AudioPool _dodgePool;
  late AudioPool _spawnPool;

  // State
  double sfxVolume = 1.0;
  double bgmVolume = 0.7;
  bool sfxMuted = false;
  bool bgmMuted = false;

  Future<void> initialize() async {
    // Preload all audio files into cache
    await FlameAudio.audioCache.loadAll([...all wav files...]);

    // Create pools for high-frequency SFX
    _dodgePool = await FlameAudio.createPool('dodge_whoosh.wav', maxPlayers: 4);
    _spawnPool = await FlameAudio.createPool('spawn_cue.wav', maxPlayers: 4);

    _initialized = true;
  }

  // Play one-shot SFX (uses pool if available, FlameAudio.play otherwise)
  void playSfx(String name, {double volume = 1.0}) { ... }

  // BGM controls
  Future<void> playBgm(String name) { ... }
  void stopBgm() { ... }
  void pauseBgm() { ... }
  void resumeBgm() { ... }

  // Cleanup
  void dispose() { ... }
}
```
