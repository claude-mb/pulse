<task type="auto">
  <name>Task 2: Wire BGM into game state lifecycle</name>
  <files>lib/game/pulse_game.dart, lib/utils/audio_manager.dart</files>
  <action>
Wire the ambient loop into the game state machine:

**PulseGame.startGame():**
- Call `audioManager.playBgm('ambient_loop');` after setting state to playing.
- BGM starts when gameplay begins.

**PulseGame.resetGame():**
- Call `audioManager.stopBgm();` then `audioManager.playBgm('ambient_loop');` to restart the loop fresh.
- Restarting the loop ensures it's in sync with the new game session.

**PulseGame.gameOver():**
- Call `audioManager.stopBgm();` to cut the music on death.
- Abrupt stop reinforces the death moment — silence after impact is powerful.

**PulseGame.pauseGame():**
- Call `audioManager.pauseBgm();` to pause music with the game.

**PulseGame.resumeGame():**
- Call `audioManager.resumeBgm();` to resume music when unpausing.

**PulseGame.returnToMenu():**
- Call `audioManager.stopBgm();` — no music on the menu screen.

Ensure AudioManager.playBgm() sets the volume to `bgmVolume` and respects `bgmMuted` flag. The BGM should play at 0.7 volume by default (set in 05-01) — noticeably quieter than SFX so it doesn't compete.

Add a guard in playBgm to handle the case where BGM is already playing (stop first, then play).
  </action>
