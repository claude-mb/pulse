<task type="auto">
  <name>Task 1: Create ProgressionRepository with XP tracking</name>
  <files>lib/utils/progression_repository.dart, lib/game/config/game_config.dart</files>
  <action>
Create a ProgressionRepository singleton following the same pattern as ScoreRepository:
- Private constructor, static instance, late SharedPreferences, initialize() method
- Persisted fields: totalXP (int), selectedShapeId (String, default 'diamond'), selectedThemeId (String, default 'neon_red')
- Getter for totalXP
- Method: addXP(int amount) → adds to totalXP and persists
- Method: setSelectedShape(String id) → persists selected shape
- Method: setSelectedTheme(String id) → persists selected theme
- Method: isUnlocked(int xpCost) → returns totalXP >= xpCost

XP design: milestone-based (XP only goes up, never spent). Items auto-unlock when totalXP reaches their XP threshold. This avoids currency management complexity and ensures players always feel forward progress.

Add to GameConfig:
- xpPerScore: 1 (1 XP per score point — simple, predictable)

Initialize ProgressionRepository in PulseGame.onLoad() after ScoreRepository.initialize().

Do NOT reuse ScoreRepository for XP — keep concerns separated. ProgressionRepository handles progression/unlocks, ScoreRepository handles score/stats.
  </action>
