  <action>
Create PlayerShape class in lib/game/models/player_shape.dart:
- Fields: id (String), name (String), xpCost (int), vertices (List&lt;Vector2&gt;) for a shape fitting within a 40×40 bounding box
- The vertices define the shape path used for both rendering and the PolygonComponent constructor
- Add a computed `path` getter that builds a Path from vertices (moveTo first, lineTo rest, close)
- Add a computed `center` getter (average of all vertices) for glow scaling origin

Define 5 shapes as static const instances on a PlayerShapes class (matching Patterns/GameConfig style):
1. **diamond** (id: 'diamond', xpCost: 0): vertices [20,0], [40,20], [20,40], [0,20] — current shape, default
2. **circle** (id: 'circle', xpCost: 500): approximate circle as 8-vertex polygon — [20,0], [34,6], [40,20], [34,34], [20,40], [6,34], [0,20], [6,6]
3. **triangle** (id: 'triangle', xpCost: 1500): equilateral-ish — [20,2], [38,36], [2,36]
4. **hexagon** (id: 'hexagon', xpCost: 3000): regular hexagon — [20,0], [38,10], [38,30], [20,40], [2,30], [2,10]
5. **star** (id: 'star', xpCost: 5000): 5-point star — alternating outer/inner vertices at appropriate angles

Add a static `all` list and a `getById(String id)` method returning the shape (with diamond as fallback).

Add XP thresholds to GameConfig for reference:
- shapeUnlockCosts: Map&lt;String, int&gt; is NOT needed since costs are on the model itself
