<task type="auto">
  <name>Task 1: Create ScoreManager component with scoring formula</name>
  <files>lib/game/managers/score_manager.dart, lib/game/config/game_config.dart</files>
  <action>
Create ScoreManager extending Component with HasGameReference<PulseGame>.

Score formula:
- Time score: accumulates at `scorePerSecond` (10.0) points per second during play
- Dodge bonus: `dodgeBonus` (25) × comboMultiplier per dodge
- Near-miss bonus: `nearMissBonus` (50) × comboMultiplier per near-miss
- Combo multiplier: 1.0 + (currentCombo × 0.1), capped at 3.0

Fields to track:
- `score` (double) — total accumulated score
- `combo` (int) — current combo count, increments on dodge and near-miss, resets on death
- `totalDodges` (int) — lifetime count for current run
- `totalNearMisses` (int) — lifetime count for current run
- `bestCombo` (int) — highest combo achieved in current run
- `lastScoreEvent` (String?) — last scoring event description for HUD flash ("DODGE +25", "NEAR MISS +50")
- `lastScoreEventTimer` (double) — countdown timer for clearing lastScoreEvent display

Methods:
- `addDodge()` — increment combo, add dodge bonus × multiplier to score, update totalDodges, set lastScoreEvent
- `addNearMiss()` — increment combo, add near-miss bonus × multiplier to score, update totalNearMisses, set lastScoreEvent
- `reset()` — zero all fields for new game
- `double get comboMultiplier` — calculated from combo count
- `int get displayScore` — score.round() for display

In update(dt): accumulate time score (game.survivalTime delta × scorePerSecond), clear lastScoreEvent after 0.8s timer.

Add scoring constants to GameConfig:
- scorePerSecond = 10.0
- dodgeBonus = 25
- nearMissBonus = 50
- maxComboMultiplier = 3.0
- comboMultiplierStep = 0.1
- scoreEventDisplayDuration = 0.8
