- `int get gamesPlayed` — 'games_played' key, default 0
- `int get allTimeBestCombo` — 'best_combo' key, default 0
- `int get allTimeTotalDodges` — 'total_dodges' key, default 0
- `double get bestSurvivalTime` — 'best_survival_time' key, default 0.0

Methods:
- `Future<void> recordGameEnd({required int score, required int bestCombo, required int totalDodges, required double survivalTime})` — single method that:
  1. Increments gamesPlayed by 1
  2. Updates bestScore if score > current best (replace existing saveBestScore call)
  3. Updates allTimeBestCombo if bestCombo > current best
  4. Accumulates allTimeTotalDodges (adds to running total)
  5. Updates bestSurvivalTime if survivalTime > current best
  Returns whether it was a new best score (bool) so caller can trigger celebration.

- Remove the standalone `saveBestScore()` method (replaced by recordGameEnd).
- Keep `isNewBest()` as a read-only check or inline it into recordGameEnd's return.

Wire in PulseGame.gameOver():
- Replace the separate `saveBestScore()` call with `recordGameEnd()`:

  ```
    bestCombo: scoreManager.bestCombo,
    totalDodges: scoreManager.totalDodges,
    survivalTime: survivalTime,
  );
  ```
- Use the returned bool for lastRunWasNewBest flag and celebration trigger.
