<task type="auto">
  <name>Task 1: Create DifficultyManager component</name>
  <files>lib/game/managers/difficulty_manager.dart, lib/game/config/game_config.dart</files>
  <action>
Create `DifficultyManager` as a Flame Component (with HasGameReference<PulseGame>) that computes difficulty based on survival time.

**Difficulty levels** (5 levels, time-based thresholds):
- Level 1: 0-10s (warmup — single patterns only)
- Level 2: 10-25s (introduce doubleGap and stagger)
- Level 3: 25-45s (introduce wave patterns)
- Level 4: 45-70s (all patterns, faster)
- Level 5: 70s+ (maximum difficulty, endgame)

**Derived values** (computed from level, smooth interpolation within each level):
- `speedMultiplier`: 1.0 at level 1 → 1.6 at level 5. Use lerp based on survival time within thresholds. Actual speed = baseSpeed * speedMultiplier.
- `intervalMultiplier`: 1.0 at level 1 → 0.55 at level 5. Actual interval = baseInterval * intervalMultiplier. Shorter interval = more frequent patterns.
- `difficultyLevel`: int 1-5 for pattern selection gating.

**Methods:**
- Getters for speedMultiplier, intervalMultiplier, difficultyLevel
- `void reset()`: Reset to initial state
- `update(double dt)`: Read game.survivalTime, recompute derived values. Only update when game.state == GameState.playing.

Add difficulty-related constants to GameConfig:
- `difficultyThresholds`: [0, 10, 25, 45, 70] (seconds for each level)
- `maxSpeedMultiplier`: 1.6
- `minIntervalMultiplier`: 0.55

Use smooth interpolation (lerp between thresholds) so difficulty ramps gradually, not in sudden jumps. The speed increase should be the PRIMARY escalation — players should feel it getting faster before patterns get harder.
  </action>

  <done>DifficultyManager computes speed/interval multipliers and difficulty level from survival time with smooth interpolation between thresholds</done>

<task type="auto">
  <name>Task 2: Wire DifficultyManager into spawner and sequencer</name>
  <files>lib/game/managers/obstacle_spawner.dart, lib/game/pulse_game.dart</files>
  <action>
Integrate DifficultyManager into the game:

**PulseGame changes:**
- Add `late DifficultyManager difficultyManager` field
- Create and add DifficultyManager to world in onLoad (alongside obstacleSpawner)
- Call difficultyManager.reset() in startGame() and resetGame()

**ObstacleSpawner changes:**
- Access DifficultyManager via game reference: `game.difficultyManager`
- In update(), use dynamic interval: `GameConfig.spawnInterval * game.difficultyManager.intervalMultiplier` instead of fixed GameConfig.spawnInterval
- When creating obstacles from pattern placements, pass dynamic speed: `GameConfig.obstacleSpeed * game.difficultyManager.speedMultiplier`
- Update sequencer difficulty: `_sequencer.setDifficulty(game.difficultyManager.difficultyLevel)` each frame (cheap operation, just sets an int)

**Key constraint:** The base values in GameConfig (speed 280, interval 1.1s) remain unchanged — they represent the Level 1 feel that was tuned in Phase 2. DifficultyManager only applies multipliers on top.

**Do NOT change:** Player speed, dodge distance, or hitbox size. Difficulty comes from obstacles, not from nerfing the player.
