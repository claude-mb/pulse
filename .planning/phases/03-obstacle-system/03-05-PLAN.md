<task type="auto">
  <name>Task 1: Add anti-repetition and variety enforcement to PatternSequencer</name>
  <files>lib/game/managers/pattern_sequencer.dart, lib/game/config/game_config.dart</files>
  <action>
Enhance PatternSequencer's `next()` method with anti-repetition:

**Anti-repetition rules:**
1. Never select the same pattern id twice consecutively (weight → 0 for last pattern)
2. Penalize patterns that appeared in the last 3 selections (weight × 0.3 for patterns in history)
3. At difficulty 2+, ensure at least 1 in every 4 patterns is NOT a single (force variety when complex patterns are available)

**Implementation in next():**
1. Get base weights for eligible patterns (difficulty-gated)
2. Apply anti-repetition penalties:
   - If pattern.id == lastPatternId: weight = 0
   - If pattern.id in _history (last 3): weight *= 0.3
3. If all eligible weights are 0 (shouldn't happen with 5 patterns), reset to base weights
4. Select using weighted random from adjusted weights
5. Update _history (push new, pop oldest if > 3)

**Variety tracking:**
- Track `_recentSingleCount`: number of "single" patterns in last 4 selections
- If _recentSingleCount >= 3 and difficulty >= 2: force a non-single pattern (set single weight to 0)

Add config constant: `maxConsecutiveSimple = 3`

Keep it simple — avoid over-engineering. The goal is "doesn't feel repetitive", not a music composition engine.

<task type="auto">
  <name>Task 2: Add rhythm system with intense and breather cycles</name>
  <files>lib/game/managers/pattern_sequencer.dart, lib/game/config/game_config.dart</files>
  <action>
Add rhythm variation to create tension/release pacing:

**Rhythm concept:**
The game alternates between "intense" phases (complex patterns, tighter timing) and "breather" phases (simpler patterns, wider gaps). This creates a heartbeat-like rhythm that prevents fatigue and makes intense moments feel more impactful.

**Implementation in PatternSequencer:**
Add rhythm state tracking:
- `_patternsSinceBreather`: int counter, incremented each pattern
- `_inBreather`: bool, true during breather phase
- `_breatherPatternsRemaining`: int, counts down during breather

**Rhythm rules (apply AFTER difficulty 2, level 1 is pure warmup):**
- After 4-6 consecutive "intense" patterns (difficulty 2+ patterns), trigger a breather
- Breather lasts 2-3 patterns of only difficulty-1 patterns (single) regardless of current difficulty level
- During breather: spawn interval multiplier gets a 1.3x bonus (slower spawning, more breathing room)
- After breather: resume normal difficulty-based selection
- The intense count threshold varies: `4 + random.nextInt(3)` to prevent predictability

**Integration with next():**
1. If `_inBreather` and `_breatherPatternsRemaining > 0`: force single pattern, decrement counter
2. If `_inBreather` and `_breatherPatternsRemaining == 0`: end breather, reset `_patternsSinceBreather = 0`
3. If not in breather and `_patternsSinceBreather >= threshold`: start breather
4. Otherwise: normal weighted selection

**Add to ObstacleSpawner:**
- Check sequencer for breather state: `_sequencer.isBreather`
- If in breather, multiply interval by 1.3 (even more breathing room)

Add config constants:
- `rhythmIntenseMin = 4`, `rhythmIntenseMax = 6`
- `rhythmBreatherLength = 2`
- `rhythmBreatherIntervalBonus = 1.3`
